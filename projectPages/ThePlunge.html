The Plunge


Im really happy with this game as how I came about the idea of the game, the game Jam i joined was the Portfolio Builders Jam #60 and there wasnt any reward or anything for this I just wanted presssure and a timeframe on myself. the them of the Jam was Take the Plunge and the first thing that came to my head was ... water, fear and then i wanted to stand out, so i thought outside of the box and came up with a plunger, then it evolved into this superhero like weapon where you literially "Take" The Plunge , (the plunger being called The Plunge, on account of it being so legendary).

for basics i wanted essential mechanics in the game. that would set the foundation of the game i set out to complete these throughout the week

The player being able to control how hard / fast they want to throw The Plunge

Have a basic arcade highscoreing system for a self defined goal.

Make the plunger have a "Quality of Stick" to make the game more dynamic,

I wanted to have this extra challenge becasue i wanted to be versed more in angles and vectors in Untiy as it was My focus for this Jam. the programming was challengint i got the grasp of it in the end, At the moment the most challenging part of this project and in unity for me personally right now is Player Inputs, i get a bit confused with how it works but becasue this project required a fair bit of it i feel my knowledge of the player Input system itself has improved. Some bugs appeared while programming like the plunger not instantiating where it was supposed to but all of that was fixed in the end.

I also learned a lot about Persistance in this Jam, as it was my first time trying to maintain data from different scenes, throughout the proccess of this project i didnt structure my scripts too well and when i went on to implament persistance i had to redesign my Session Manager Script and create a new PersistanceManager script, this taught about persistance across scenes in unity.

Also to impress upon you that my focus was souly programming. the Assest that were used in this jam where all from the Unity Asset Store for Free as i wasnt planning on spending time on assets and stuff myself for this jam. the only file i created myself was the naration at the begining of the game by using a voice changer.
